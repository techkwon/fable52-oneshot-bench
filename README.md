# Fable 5.2 vs Opus 5.5 vs GPT-6.1 Sol — 원샷 코딩 5라운드

웹에 공개된 프롬프트 5개를 세 모델(`claude-fable-5-2`, `claude-opus-5-5`, `gpt-6.1-sol`)에게 한 번씩만 시킨 결과입니다.

- `index.html` — 프롬프트 원문, 결과물, 블라인드 심사 기록을 보는 페이지
- `results/<과제>/<모델>/` — 모델이 만든 파일 그대로
- `rec/` — 결과물을 실행해 녹화한 영상(압축본)
- `judge/` — 심사위원(세 모델)이 본 익명 캡처
- `harness/` — 실행·녹화·심사 스크립트
- `data.json` — 시간, 비용, 투표, 점수

규칙과 한계는 페이지의 "규칙과 한계"에 적었습니다. 과제마다 1회만 실행했으므로 다시 돌리면 결과가 달라질 수 있습니다.
